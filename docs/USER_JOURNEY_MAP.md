# ArtNex 유저 저니 맵 (User Journey Map)

**버전**: 1.0  
**작성일**: 2026-02-02

---

## 1. 페르소나 정의

### 페르소나 1: 스타트업 창업자 (민지, 29세)
- **배경**: 뷰티 스타트업 창업 준비 중
- **목표**: 차별화된 브랜드 아이덴티티 구축
- **페인포인트**: 브랜딩 예산 부족, 전문 지식 부재
- **니즈**: 저렴하고 빠른 브랜드 개발

### 페르소나 2: 마케팅 담당자 (준호, 35세)
- **배경**: 중소기업 마케팅팀 근무
- **목표**: 브랜드 리뉴얼 및 마케팅 전략 수립
- **페인포인트**: 대행사 비용 부담, 리소스 부족
- **니즈**: 합리적인 마케팅 솔루션

### 페르소나 3: 프리랜서 브랜드매니저 (수현, 32세)
- **배경**: 프리랜서 브랜딩 전문가
- **목표**: 새로운 클라이언트 확보
- **페인포인트**: 고객 발굴 어려움
- **니즈**: 안정적인 프로젝트 소싱

## 2. 유저 저니: 스타트업 창업자 (민지)

### 2.1 전체 여정 개요

```
[인지] → [탐색] → [회원가입] → [브랜드 생성] → [학습/관리] → [전문가 상담] → [재방문]
```

### 2.2 단계별 상세

#### Stage 1: 인지 (Awareness)
| 항목 | 내용 |
|------|------|
| **터치포인트** | SNS 광고, 블로그, 지인 추천 |
| **사용자 행동** | "AI 브랜드 만들기" 검색 후 ArtNex 발견 |
| **사용자 생각** | "AI로 브랜드를 만들 수 있다고? 신기하네" |
| **감정** | 호기심, 기대 |
| **기회** | SEO 최적화, 성공 사례 콘텐츠 |

#### Stage 2: 탐색 (Exploration)
| 항목 | 내용 |
|------|------|
| **터치포인트** | 메인페이지 (/) |
| **사용자 행동** | 서비스 소개 읽기, 데모 확인 |
| **사용자 생각** | "비용 절감 효과가 48%나 된다고?" |
| **감정** | 관심, 약간의 의심 |
| **기회** | 구체적인 성과 지표, 고객 후기 |

#### Stage 3: 회원가입 (Registration)
| 항목 | 내용 |
|------|------|
| **터치포인트** | 회원가입 페이지 (/register) |
| **사용자 행동** | 이메일, 비밀번호, 이름 입력 |
| **사용자 생각** | "간단하네. 일단 가입해보자" |
| **감정** | 기대감 |
| **페인포인트** | 소셜 로그인 미지원 |
| **기회** | 카카오/구글 소셜 로그인 추가 |

#### Stage 4: 브랜드 생성 (Creation)
| 항목 | 내용 |
|------|------|
| **터치포인트** | 브랜드 개발 페이지 (/brand-develop) |
| **사용자 행동** | 프롬프트 입력, AI 결과 확인 |
| **사용자 생각** | "와, 진짜 브랜드가 나왔어! 슬로건도 괜찮네" |
| **감정** | 놀라움, 만족 |
| **페인포인트** | 결과가 마음에 안 들 수 있음 |
| **기회** | 여러 버전 생성, 세부 조정 기능 |

#### Stage 5: 학습/관리 (Learning)
| 항목 | 내용 |
|------|------|
| **터치포인트** | AI 매니저 페이지 (/ai-manager) |
| **사용자 행동** | 요약 확인, 퀴즈 풀기, AI 튜터 질문 |
| **사용자 생각** | "브랜드에 대해 더 깊이 이해하게 됐어" |
| **감정** | 성취감, 자신감 |
| **기회** | 브랜드 자산(로고, 컬러 등) 생성 기능 |

#### Stage 6: 전문가 상담 (Consultation)
| 항목 | 내용 |
|------|------|
| **터치포인트** | 브랜드매니저 페이지 (/brand-manager) |
| **사용자 행동** | 프리랜서 검색, 상담 신청 |
| **사용자 생각** | "전문가 조언도 받아보고 싶어" |
| **감정** | 기대, 약간의 부담 (비용) |
| **기회** | 무료 상담, 견적 미리보기 |

#### Stage 7: 재방문 (Return)
| 항목 | 내용 |
|------|------|
| **터치포인트** | 이메일, 푸시 알림 |
| **사용자 행동** | 지원사업 확인, 마케팅 서비스 검토 |
| **사용자 생각** | "지원사업으로 마케팅 비용 해결할 수 있겠다" |
| **감정** | 신뢰, 충성 |
| **기회** | 맞춤 지원사업 알림, 할인 프로모션 |

## 3. 유저 저니: 마케팅 담당자 (준호)

### 3.1 전체 여정 개요

```
[문제 인식] → [솔루션 탐색] → [마케팅 서비스 검토] → [상담 신청] → [서비스 이용]
```

### 3.2 단계별 상세

#### Stage 1: 문제 인식
| 항목 | 내용 |
|------|------|
| **상황** | 대행사 비용이 너무 비싸고 결과도 불확실 |
| **니즈** | 합리적인 가격에 효과적인 마케팅 |

#### Stage 2: 솔루션 탐색
| 항목 | 내용 |
|------|------|
| **터치포인트** | 메인페이지, 마케팅 페이지 |
| **사용자 행동** | 성과 지표 확인 (ROAS 420%) |
| **사용자 생각** | "성과가 괜찮네. 서비스 종류도 다양하고" |

#### Stage 3: 마케팅 서비스 검토
| 항목 | 내용 |
|------|------|
| **터치포인트** | 마케팅 페이지 (/marketing) |
| **사용자 행동** | 카테고리별 서비스 비교, 가격 확인 |
| **사용자 생각** | "인스타 운영이랑 메타 광고를 같이 하면 좋겠다" |

#### Stage 4: 상담 신청
| 항목 | 내용 |
|------|------|
| **터치포인트** | 서비스 카드 "상담하기" 버튼 |
| **사용자 행동** | 상담 폼 작성, 요구사항 전달 |
| **기회** | 실시간 채팅 상담, 빠른 견적 |

#### Stage 5: 서비스 이용
| 항목 | 내용 |
|------|------|
| **사용자 행동** | 서비스 진행, 성과 리포트 확인 |
| **기회** | 대시보드, 실시간 성과 모니터링 |

---

## 4. 핵심 터치포인트 분석

### 4.1 전환 퍼널

```
방문 (100%) → 회원가입 (30%) → 브랜드 생성 (70%) → 상담 신청 (20%) → 결제 (10%)
```

### 4.2 주요 이탈 지점

| 단계 | 이탈 원인 | 개선 방안 |
|------|----------|----------|
| 메인→회원가입 | 소셜 로그인 미지원 | 카카오/구글 로그인 추가 |
| 브랜드 생성 | 결과 불만족 | 재생성, 세부 조정 기능 |
| 상담 신청 | 가격 부담 | 무료 상담, 견적 투명화 |

## 5. 감정 곡선 (Emotion Curve)

```
감정
  ^
  |     ★ 브랜드 생성 완료
  |    /  \
  | ★/    \★ AI 매니저 학습
  |/회원가입  \
★ 탐색          \
  |              ★ 상담 신청 (비용 걱정)
  |                \
  |                 ★ 서비스 이용 후 만족
  +------------------------→ 시간
```

## 6. 개선 기회 (Opportunities)

### 6.1 단기 개선 (1-2주)
- [ ] 소셜 로그인 (카카오, 구글)
- [ ] 브랜드 여러 버전 생성
- [ ] 상담 견적 미리보기

### 6.2 중기 개선 (1-2개월)
- [ ] 실시간 채팅 상담
- [ ] 마케팅 대시보드
- [ ] 브랜드 자산 (로고, 컬러팔레트) 생성

### 6.3 장기 개선 (3-6개월)
- [ ] 모바일 앱
- [ ] 브랜드 성장 트래킹
- [ ] 커뮤니티 기능

## 7. 성공 지표 (KPIs)

| 지표 | 목표 | 측정 방법 |
|------|------|----------|
| 회원가입 전환율 | 30% | GA 퍼널 분석 |
| 브랜드 생성율 | 70% | 로그 분석 |
| 상담 신청율 | 20% | CRM 연동 |
| NPS | 50+ | 설문조사 |
| 재방문율 | 40% | GA 코호트 분석 |
