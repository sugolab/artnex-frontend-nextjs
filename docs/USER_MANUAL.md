## 1. 서비스 소개

### ArtNex란?
ArtNex는 AI 기술을 활용하여 누구나 쉽게 브랜드를 만들 수 있는 플랫폼입니다.

### 주요 기능
- **AI 브랜드 생성**: 아이디어만 입력하면 브랜드명, 슬로건, 컨셉 자동 생성
- **전문가 매칭**: 브랜딩/마케팅 전문 프리랜서 연결
- **마케팅 솔루션**: SNS, 퍼포먼스, 콘텐츠 마케팅 서비스
- **지원사업 추천**: AI 기반 맞춤형 정부지원사업 안내

## 2. 시작하기

### 2.1 회원가입

1. 상단 메뉴의 **"무료 시작"** 버튼을 클릭합니다.
2. 필수 정보를 입력합니다:
   - 이메일 주소
   - 비밀번호 (8자 이상)
   - 비밀번호 확인
   - 이름
3. 약관에 동의합니다:
   - [필수] 이용약관
   - [필수] 개인정보 처리방침
   - [선택] 마케팅 수신
4. **"가입하기"** 버튼을 클릭하면 완료됩니다.

### 2.2 로그인

1. 상단 메뉴의 **"로그인"**을 클릭합니다.
2. 가입한 이메일과 비밀번호를 입력합니다.
3. 자동로그인을 원하시면 체크박스를 선택합니다.
4. **"로그인"** 버튼을 클릭합니다.

### 2.3 비밀번호 찾기

1. 로그인 페이지에서 **"비밀번호 찾기"**를 클릭합니다.
2. 가입한 이메일을 입력합니다.
3. 이메일로 전송된 링크를 통해 비밀번호를 재설정합니다.

## 3. 브랜드 개발

### 3.1 AI 브랜드 생성하기

1. 메인 메뉴에서 **"브랜드 개발"**을 클릭합니다.
2. 검색창에 원하는 브랜드를 설명합니다.

**입력 예시:**
- "여성 MZ세대를 겨냥한 네일케어 브랜드를 만들고 싶어"
- "지속가능성과 디자인을 모두 갖춘 리빙 브랜드를 만들어줘"
- "20대 여성을 위한 럭셔리 스킨케어 브랜드를 만들고 싶어"

3. **"검색"** 버튼을 클릭하면 AI가 분석을 시작합니다.
4. 잠시 후 결과가 표시됩니다:
   - 브랜드명
   - 슬로건
   - 컨셉 설명
   - 관련 태그

### 3.2 추천 프롬프트 사용하기

아이디어가 떠오르지 않으시다면, 화면에 표시된 **추천 프롬프트**를 클릭하세요.
자동으로 검색창에 입력됩니다.

### 3.3 결과 활용하기

브랜드가 생성되면 3가지 옵션을 선택할 수 있습니다:

| 버튼 | 설명 |
|------|------|
| AI 매니저로 관리하기 | 생성된 브랜드를 학습하고 관리합니다 |
| 브랜드매니저 상담 | 전문가와 상담을 진행합니다 |
| 다시 | 새로운 브랜드를 생성합니다 |

## 4. 브랜드매니저 찾기

### 4.1 프리랜서 검색

1. 메인 메뉴에서 **"브랜드매니저"**를 클릭합니다.
2. **"프리랜서 찾기"** 탭이 기본 선택되어 있습니다.
3. 검색창에 프리랜서 이름이나 전문분야를 입력합니다.
4. 원하는 프리랜서 카드의 **"상담하기"**를 클릭합니다.

### 4.2 프리랜서 정보 확인

각 프리랜서 카드에서 확인할 수 있는 정보:
- **카테고리**: 브랜딩, 마케팅, 디자인, SNS, 영상
- **별점/리뷰**: 이전 고객들의 평가
- **전문분야 태그**: 세부 전문 영역

### 4.3 프로젝트 등록

1. **"프로젝트 찾기"** 탭을 클릭합니다.
2. 진행 중인 프로젝트를 둘러보거나 새 프로젝트를 등록합니다.

## 5. 마케팅 서비스

### 5.1 서비스 둘러보기

1. 메인 메뉴에서 **"마케팅"**을 클릭합니다.
2. 상단에 ArtNex 마케팅 성과가 표시됩니다:
   - 평균 ROAS: 420%
   - 마케팅 캠페인: 300+
   - 총 도달 수: 50M+
   - 고객 만족도: 98%

### 5.2 카테고리 필터

원하는 서비스 유형을 필터링합니다:
- **전체**: 모든 서비스 표시
- **SNS 마케팅**: 인스타그램, 틱톡 등 SNS 운영
- **퍼포먼스**: 메타/구글 광고 운영
- **콘텐츠**: 영상, 이미지 콘텐츠 제작
- **인플루언서**: 인플루언서 마케팅 캠페인

### 5.3 서비스 신청

1. 원하는 서비스 카드를 확인합니다.
2. 포함 항목과 가격을 확인합니다.
3. **"상담하기"** 버튼을 클릭하여 문의합니다.

## 6. 지원사업 찾기

### 6.1 지원사업 검색

1. 메인 메뉴에서 **"지원사업"**을 클릭합니다.
2. 원하는 카테고리를 선택합니다:
   - 창업지원
   - 마케팅
   - R&D
   - 수출
   - 인력

### 6.2 접수 상태 필터

- **전체**: 모든 지원사업
- **접수중**: 현재 신청 가능한 사업
- **접수예정**: 곧 신청이 시작되는 사업

### 6.3 AI 맞춤 추천

1. 상단의 **"AI 추천받기"** 버튼을 클릭합니다.
2. 브랜드 정보를 입력하면 AI가 적합한 지원사업을 추천합니다.

### 6.4 지원사업 상세 확인

각 카드에서 확인할 수 있는 정보:
- 사업명
- 주관기관
- 지원금액
- 마감일
- 접수상태

**"자세히 보기"**를 클릭하면 상세 정보 페이지로 이동합니다.

## 7. AI 매니저

### 7.1 브랜드 학습하기

AI 매니저는 생성된 브랜드를 학습하고 관리하는 도구입니다.

**화면 구성:**
- **왼쪽**: 브랜드 카드 (브랜드 기본 정보)
- **오른쪽**: 학습 도구 (탭 형식)

### 7.2 탭별 기능

#### 요약 탭
브랜드의 핵심 정보를 한눈에 확인합니다:
- 브랜드 비전
- 핵심 가치
- 경쟁 우위

#### 퀴즈 탭
브랜드 이해도를 테스트합니다:
- 객관식 문제 풀이
- 정답 확인 및 해설

#### 개념 탭
브랜드 관련 핵심 용어를 학습합니다:
- 클린뷰티
- 비건 화장품
- EWG 등급
- 업사이클링

#### 메모 탭
브랜드에 대한 아이디어나 메모를 작성합니다:
1. 텍스트 입력란에 내용을 작성합니다.
2. **"저장하기"** 버튼을 클릭합니다.

#### AI 튜터 탭
브랜드에 대해 AI와 대화합니다:
1. 하단 입력창에 질문을 입력합니다.
2. Enter 또는 **"전송"** 버튼을 클릭합니다.
3. AI가 브랜드 맥락에 맞는 답변을 제공합니다.

## 8. FAQ

### Q1. 회원가입 없이 이용할 수 있나요?
A. 메인페이지와 서비스 소개는 로그인 없이 볼 수 있습니다. 브랜드 생성, 상담 신청 등 핵심 기능은 회원가입이 필요합니다.

### Q2. AI가 생성한 브랜드의 저작권은 누구에게 있나요?
A. 생성된 브랜드의 저작권은 사용자에게 귀속됩니다. 단, 실제 사업 등록 전 상표 등록 여부를 확인하시기 바랍니다.

### Q3. 브랜드매니저 상담 비용은 얼마인가요?
A. 초기 상담은 무료입니다. 이후 프로젝트 진행 시 매니저별 견적을 확인하실 수 있습니다.

### Q4. 지원사업 신청을 대행해주나요?
A. ArtNex는 지원사업 정보 제공 및 매칭 서비스를 제공합니다. 실제 신청은 사용자가 직접 진행하셔야 합니다.

### Q5. 모바일에서도 이용 가능한가요?
A. 현재 데스크톱 환경에 최적화되어 있습니다. 모바일 버전은 준비 중입니다.
