## AI 브랜드 개발 플랫폼

**버전**: 2.0  
**작성일**: 2026-02-02  
**작성자**: 뚜리 (OpenClaw)

---

## 1. 제품 개요

### 1.1 제품 비전
AI 기술을 활용하여 누구나 쉽게 브랜드를 개발하고, 전문 브랜드매니저 연결, 마케팅 솔루션, 정부지원사업까지 원스톱으로 제공하는 플랫폼

### 1.2 핵심 가치
- **AI 브랜드 생성**: 간단한 아이디어만으로 브랜드 컨셉, 네이밍, 슬로건 자동 생성
- **전문가 매칭**: 검증된 브랜드매니저/프리랜서와 실시간 연결
- **마케팅 솔루션**: SNS, 퍼포먼스, 콘텐츠 마케팅 패키지 제공
- **지원사업 연결**: AI 기반 맞춤형 정부지원사업 추천

### 1.3 기술 스택
```
Frontend: Next.js 14 (App Router) + TypeScript
Styling: Tailwind CSS
배포: Vercel (예정)
```

## 4. 기능 요구사항

### 4.1 메인페이지 (/)
**목적**: 서비스 소개 및 사용자 유입

**섹션 구성**:
1. **히어로 섹션**: 헤드라인, 서브카피, CTA 버튼
2. **AI 브랜드 데모**: 프롬프트 입력 예시, 결과 미리보기
3. **스마트 브랜드 관리**: 비용 절감 시뮬레이터
4. **서비스 카드**: 4개 핵심 서비스 링크

**CTA**:
- "브랜드 개발 시작" → `/brand-develop`
- "브랜드매니저 찾기" → `/brand-manager`

### 4.2 로그인 (/login)
**목적**: 사용자 인증

**기능**:
- 이메일/비밀번호 입력
- 자동로그인 체크박스
- 비밀번호 찾기 링크
- 회원가입 링크

**레이아웃**: 좌측 폼 (494px) + 우측 이미지 (673px)

### 4.3 회원가입 (/register)
**목적**: 신규 사용자 등록

**필수 입력**:
- 이메일
- 비밀번호 (8자 이상)
- 비밀번호 확인
- 이름

**선택 입력**:
- 휴대폰 번호

**약관 동의**:
- [필수] 이용약관
- [필수] 개인정보 처리방침
- [선택] 마케팅 수신

### 4.4 브랜드 개발 (/brand-develop)
**목적**: AI 기반 브랜드 생성

**기능**:
1. **프롬프트 입력**: 원하는 브랜드 설명
2. **추천 프롬프트**: 3개 예시 제공
   - 감성 키워드 중심
   - 가치중심 브랜드
   - 타겟 중심 브랜드
3. **AI 분석**: 로딩 애니메이션
4. **결과 표시**:
   - 브랜드명
   - 슬로건
   - 컨셉 설명
   - 태그
5. **액션 버튼**:
   - AI 매니저로 관리하기
   - 브랜드매니저 상담
   - 다시 생성

### 4.5 브랜드매니저 (/brand-manager)
**목적**: 프리랜서/프로젝트 매칭

**탭 구조**:
- 프리랜서 찾기 (기본)
- 프로젝트 찾기

**필터**:
- 검색어 (프리랜서명)

**카드 정보**:
- 프로필 이미지
- 카테고리 (브랜딩/마케팅/디자인/SNS/영상)
- 이름, 직함
- 별점, 리뷰 수
- 태그
- 상담하기 버튼

### 4.6 마케팅 (/marketing)
**목적**: 마케팅 서비스 소개 및 상담 연결

**섹션**:
1. **통계 배너**: ROAS, 캠페인 수, 도달, 만족도
2. **카테고리 필터**: 전체/SNS/퍼포먼스/콘텐츠/인플루언서
3. **서비스 그리드**:
   - 서비스명
   - 설명
   - 포함 항목 (체크리스트)
   - 가격
   - 상담하기 버튼

### 4.7 지원사업 (/support)
**목적**: 정부지원사업 검색 및 추천

**섹션**:
1. **AI 추천 배너**: 맞춤 지원사업 추천 CTA
2. **필터**:
   - 카테고리 (창업/마케팅/R&D/수출/인력)
   - 접수상태 (접수중/접수예정)
3. **지원사업 카드**:
   - 접수상태 뱃지
   - 사업명, 주관기관
   - 설명
   - 지원금액, 마감일
   - 자세히 보기 버튼

### 4.8 AI 매니저 (/ai-manager)
**목적**: 생성된 브랜드 학습 및 관리

**레이아웃**: 좌측 브랜드카드 (320px) + 우측 탭 콘텐츠

**좌측 브랜드 카드**:
- 브랜드 이미지
- 브랜드명, 슬로건
- 설명
- 태그
- 상세 정보 (카테고리, 타겟, 가격대, 판매채널)

**우측 탭**:
| 탭 | 기능 |
|----|------|
| 요약 | 브랜드 비전, 핵심가치, 경쟁우위 |
| 퀴즈 | 브랜드 이해도 테스트 |
| 개념 | 관련 용어 설명 |
| 메모 | 사용자 메모 작성/저장 |
| AI 튜터 | 챗봇 Q&A |

## 5. 비기능 요구사항

### 5.1 성능
- 페이지 로드: 3초 이내
